# Katkı Rehberi

1. Değişiklik için kısa bir issue açın veya mevcut issue'yu referanslayın.
2. Küçük, tek amaçlı bir dal oluşturun.
3. `npm run verify` komutunu çalıştırın.
4. Chrome'da eklentiyi yeniden yükleyip gerçek bir sayfada davranışı doğrulayın.
5. Pull request açıklamasına test edilen siteyi, medya türünü ve bilinen sınırlamaları yazın.

Örneklerde kişisel pano adresleri, oturum bilgileri veya telifli medya dosyaları eklemeyin.
